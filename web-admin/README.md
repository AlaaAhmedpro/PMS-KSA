# Super Admin — منصة إدارة الاشتراكات

مشروع React مستقل لمسؤول المنصة (مستأجرون / خطط / طلبات عرض / تعيين Org Admin).

## التشغيل

```bash
cd web-admin
npm install
npm run dev
```

الرابط: **http://127.0.0.1:5175**

## Demo Mode

مصادقة محاكاة فقط (`VITE_DEMO_MODE`). كلمة المرور الافتراضية `demo1234`. Rate-limit بعد 5 محاولات فاشلة.

من صفحة المستأجرين يمكن:

1. إنشاء منظمة (توليد `organizationId` مرتبط بالبذرة)
2. تعيين مسؤول مؤسسة (Org Admin) مع البريد والاسم

مستأجر نماء التجريبي مرتبط بـ `organizationId: org-namaa` و`admin@namaa.sa` في web-core.
