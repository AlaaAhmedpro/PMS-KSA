# منظومة إدارة المشاريع والمهام — شركة نماء للتطوير (Demo)

نسخة تجريبية تفاعلية (React + Vite) لمنظومة **إدارة المشاريع والمهام** لشركة **نماء للتطوير** — قطاع تقنية المعلومات. الواجهة RTL بالكامل مع نفس كثافة العرض: لوحة مؤشرات، مشاريع، مهام، أخبار، صلاحيات، تقارير، أرشيف، وإدارة المنصة للمستأجرين.

## التشغيل محلياً

```bash
cd web
npm install
npm run dev
```

الافتراضي: `http://localhost:5173`

## البناء للإنتاج

```bash
cd web
npm install
npm run build
npm run preview
```

## حسابات العرض التجريبي

كلمة المرور في النسخة التجريبية: أي قيمة (التحقق بالبريد فقط).

| الدور | الاسم | البريد |
|--------|--------|--------|
| مدير النظام | عبدالله محمد العتيبي | `admin@namaa.sa` |
| مسؤول المنصة | نورة فهد الشمري | `platform@namaa.sa` |
| مكتب PMO | ريم سعد الغامدي | `pmo@namaa.sa` |
| مدير فرع | خالد عبدالرحمن القحطاني | `manager.riyadh@namaa.sa` |
| عضو فريق | ياسمين فهد الحربي | `employee@namaa.sa` |
| التواصل المؤسسي | هدى سلمان الدوسري | `pr@namaa.sa` |
| الإدارة العليا | م. طارق إبراهيم الزهراني | `executive@namaa.sa` |

يمكن أيضاً استخدام **الدخول السريع** من شاشة تسجيل الدخول.

## مسارات رئيسية

- `/` — لوحة المؤشرات
- `/projects` — المشاريع
- `/tasks` — المهام
- `/platform/tenants` — المستأجرون (مدير النظام / مسؤول المنصة)
- `/platform/plans` — خطط الاشتراك
- `/platform/demo-requests` — طلبات العرض التجريبي

## التخزين المحلي

البيانات التجريبية تُحفظ في `localStorage` ببادئة `pms_`. عند تحديث بيانات العرض، يُزاد `DEMO_DATA_VERSION` في `src/lib/demoSeed.ts` لإعادة تحميل البذرة.
